# Superstore Sales Analysis

## 📊 Project Overview
This project analyzes Superstore sales data to identify key insights on profit, sales, customer segments, and regional performance.

## 🎯 Objectives
- Find most profitable products & categories
- Analyze sales trends by region & segment
- Identify loss-making products
- Create visualizations for business decisions

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Excel
- GitHub

## 📈 Key Insights
- Technology category has highest sales
- West region is most profitable
- Consumer segment brings maximum customers

## 📂 Files in this repo
- Superstore.csv (Dataset)
- Analysis.ipynb (Python Code)
- Dashboard.xlsx (Excel Dashboard)
